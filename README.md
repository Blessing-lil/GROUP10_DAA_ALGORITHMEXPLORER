# Algorithm Explorer

A JavaFX project for exploring algorithms and comparing their approaches.

## Requirements

- JDK 17 or newer
- Maven

## Run

From the project root:

```shell
mvn clean javafx:run
```

## Project layout

```text
src/main/java/com/algolab/   Java application source
src/main/resources/          JavaFX resources
docs/                        Project documentation
pom.xml                      Maven build configuration
```

The Maven `target/` directory contains generated build output and is excluded
from Git.
